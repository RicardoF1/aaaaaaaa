## 3. Historias de Usuario completadas en este Sprint

- **US-001:** Backend NestJS + Frontend React + Postgres 16 Docker en puerto 5433, JWT + Argon2id, bootstrap admin con `BOOTSTRAP_ADMIN_EMAIL/PASSWORD`, Swagger `/api/docs`.
- **US-002:** Cookie HttpOnly `SameSite=Lax`, restauración F5 con `GET /auth/me`, migración cookie v1 a v2 sin renovar JWT, logout `204` que limpia cookie, sin `localStorage` para tokens.
- **US-003:** Solo `Administrador` lista/crea/edita `email, rol_id, estado ACTIVO/INACTIVO/BLOQUEADO`. 4 roles línea base: Administrador, Operador/Técnico, Usuario Final/Conductor, Auditor Externo. Sin DELETE físico, sin CRUD roles. 89 tests backend + 54 frontend + 28 integración + 7 E2E OK, cobertura backend 100%, frontend 97.47%.
- **US-004 (parcial):** Transacción Cliente mínimo + Pedido, validaciones peso>0, volumen>0, `ventana_fin>ventana_inicio` ISO8601 UTC, `prioridad EXPRESS/ESTANDAR/ECONOMICO`, `tipo PERECEDERO/NO_PERECEDERO`, estado `PENDIENTE`. Autoriza Administrador y Operador/Técnico por decisión explícita. 121 tests backend + 82 frontend + 63 integración + 14 E2E OK.

## 4. Demostración del trabajo completado

Demostración a los stakeholders de las funcionalidades implementadas:

1. `docker compose up -d postgres` + `npm run start:dev` / `npm run dev`, login admin en `http://localhost:5173/login`.
2. Crear usuario nuevo en `/usuarios/nuevo`, duplicado devuelve `409`, F5 conserva sesión, logout redirige a `/login` y bloquea `/usuarios` directo.
3. Registrar pedido en `/pedidos/nuevo` con `Prueba manual US-004 / Destino Huancayo / -12.065,-75.204 / 2.5kg / 0.015m3`, respuesta `201` con `pedido_id` UUID y estado Pendiente, verificado en Swagger `http://localhost:3000/api/docs`.
